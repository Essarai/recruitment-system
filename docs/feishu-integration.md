# 飞书接入与本地联调

现有招聘账号登录后，在右上角“绑定飞书”完成 OAuth。飞书身份仅关联当前系统账号，不新建系统用户、不改变权限。凭据只放被 Git 忽略的服务端配置中。

## 配置

- FEISHU_APP_ID、FEISHU_APP_SECRET：飞书企业自建应用凭据。
- FEISHU_OAUTH_REDIRECT_URI：本地 http://localhost:4173/api/feishu/bind/callback；上线改成实际 HTTPS 域名的相同路径，在飞书安全设置中登记完整地址。
- PUBLIC_ORIGIN：用户打开的系统地址，生产环境必须 HTTPS。
- FEISHU_TENANT_KEY：限制绑定的企业。建议生产环境设置。
- FEISHU_PILOT_USER_ID：本地试用只允许这一系统账号的任务进入同步；该变量优先于管理页面的同步范围；清空变量后由管理端选择单账号或所有面试官。不是飞书 open_id。
- FEISHU_VERIFICATION_TOKEN、FEISHU_ENCRYPT_KEY：可选事件回调配置。未配置时每约 60 秒轮询系统关联的飞书日程，不影响本地测试。

管理员在“飞书同步”页面设置应用具备 owner/writer 权限的日历 ID，并启用同步。新任务约每 15 秒进入处理；现有待办和未来面试须点击“补同步”。配置界面仅展示面试官自行绑定的结果，不支持管理员输入 open_id 代绑。

## 能力与边界

- 待确认简历发送机器人卡片；通过/不通过仍在招聘系统处理。
- 排期创建日程并邀请面试官；修改、取消排期同步到同一个日程。创建采用幂等键，先保存远端日程 ID，再添加参与人，失败重试不重复创建。
- 接受、拒绝和暂定邀请仅更新参会回复，不提交面评，不终止应聘。
- 飞书侧改期或取消生成待确认变更。发起该应聘的 HR 或管理员可接受/拒绝；接受时重新检查可用时间和冲突，拒绝则将飞书恢复到系统安排。
- 面试官编辑飞书日程需开启对应设置；飞书该能力也允许邀请他人，请按企业实际规则设置。
- 只核对招聘系统关联的日程，不导入个人其他日程。已提交面评的历史日程保留，不再自动改写。
- 本地系统链接仅本机可用；其他设备使用需正式 HTTPS 部署。

## 验收

1. 用试用账号绑定，确认本人飞书身份正确。
2. 保存一场未来面试，查看“飞书同步”：已同步、参会回复待回复。
3. 飞书接受邀请，等待约 60 秒，再刷新系统同步状态。
4. 飞书修改开始时间，确认系统出现待 HR 确认，原排期不变。
5. 原 HR 接受/拒绝变更，确认实际排期和飞书保持一致。
6. 取消一轮面试，确认仅取消对应日程，应聘和简历仍保留。

事件回调地址为 PUBLIC_ORIGIN/api/feishu/events，独立于账号绑定回调。需配置日程变更事件并完成日历订阅；没有完成事件配置时保留轮询即可。
